# localts-snipeinator
Python script to automatically purchase an alt from localts when it's in stock, uses the api

# How to run
## Step 1
Make sure python is installed, as well as the requests library (to install it, you run "pip install requests", then clone the repository
## Step 2
In your terminal, run "python main.py"
## Step 3
Paste in your api key when prompted to

Your alt will be returned in the format of Username:Refreshtoken, copy the refresh token and paste it in your client
